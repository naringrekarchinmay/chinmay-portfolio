COVID-19 SQL Exploration

The SQL behind the dashboard: joins, window functions, CTEs, and temp tables used to explore global COVID-19 data in SQL Server.

View SQL file on GitHub See the resulting dashboard

Before any chart existed, this project lived in SQL. Using SQL Server, global COVID-19 case, death, and vaccination data was explored question by question: What's the likelihood of death by country? What share of each population was infected? How do continents compare? How does rolling vaccination coverage evolve?

The query file demonstrates practical analytical SQL joins across cases and vaccinations tables, window functions for rolling totals, CTEs and temp tables for layered calculations, and views created to feed visualization downstream. Those outputs became the COVID-19 Tableau dashboard.
