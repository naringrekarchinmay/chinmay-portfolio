Bike Buyers Excel Dashboard

A classic end-to-end Excel project: raw customer data cleaned, analyzed, and turned into an interactive dashboard revealing who actually buys bikes.

Download Excel file from GitHub

Excel remains the most universal analytics tool in business, and this project shows the full workflow: messy customer data in, decision-ready dashboard out.

After cleaning the raw dataset — deduplicating records, standardizing categories, and bucketing ages — pivot tables surface the relationships between purchase behavior and income, commute distance, age bracket, gender, and marital status. Interactive slicers let a business user filter the entire dashboard in one click.
