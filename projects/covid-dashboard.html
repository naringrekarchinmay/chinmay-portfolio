COVID-19 Global Dashboard

From SQL exploration to executive dashboard: global death percentages, infection rates, continent-level comparisons, and projected trends.

Open in Tableau Public View the SQL behind it

This dashboard is the visualization layer of a two-part project. The analysis began in SQL Server, where global COVID-19 data was explored, aggregated, and shaped; the curated outputs were then brought into Tableau as a public-health overview.

The dashboard presents global death percentage, percent of population infected by country, continent-level death counts, and a forecast view projecting infection trends, the kind of layered view that takes a reader from headline numbers to geographic detail.
