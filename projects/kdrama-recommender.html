K-Drama Analytics & Recommender

A personalized recommendation and analytics app built from drama metadata and my own ratings. It learns my taste profile, then suggests what to watch next.

GitHub Repo

Streaming platforms recommend what's popular. This project recommends what I would actually like by learning from a dataset of K-drama metadata combined with my own personal ratings.

The system analyzes my taste profile across genres, themes, and attributes, then uses NLP techniques on drama metadata to compute similarity and surface personalized suggestions for unwatched shows. The whole experience is packaged as a multi-page Streamlit app with analytics views alongside the recommender.

It's a compact, end-to-end demonstration of the core ideas behind content-based recommendation: representing items as features, modeling user preference from rating history, and ranking candidates by fit.

Highlights

What it does.

🎭

Taste profiling

Analytics on my rating history reveal which genres, tones, and attributes consistently score highest.

🔤

NLP-based similarity

Drama metadata is converted into text features so similar shows can be found by content, not just by genre tags.

⭐

Personalized ranking

Unwatched dramas are scored against the learned taste profile and ranked into a watch-next list.

🖥️

Multi-page Streamlit app

Separate pages for analytics, exploration, and recommendations, complete with poster artwork handling.
