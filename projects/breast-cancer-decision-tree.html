Breast Cancer Decision Tree Classifier

A fully evaluated decision-tree model that classifies tumors from cell-nuclei features — with the entire train, test, evaluate, and visualize workflow done properly.

GitHub Repo

Classification fundamentals, done end to end. This project trains a decision-tree model on cell-nuclei measurements to classify breast tumors, then evaluates it the way a real model should be evaluated — not just with accuracy, but with a confusion matrix and a hard look at where the model gets it wrong.

The decision tree itself is visualized, which is the point: unlike black-box models, every prediction can be traced down a readable path of feature thresholds. In a healthcare context, that interpretability matters as much as raw performance.

It's a foundational project, but the discipline it demonstrates — clean splits, honest evaluation, visual interpretation — is the same discipline behind every larger ML project in this portfolio.

Highlights

What it does.

🔬

Cell-nuclei features

Models tumor class from quantitative measurements of cell nuclei in the dataset.

🌳

Interpretable by design

🧮

Confusion matrix evaluation

Performance is assessed on true/false positives and negatives — the metrics that actually matter in a medical setting.

✅

Proper methodology

Clean train/test split, fitted on training data only, evaluated on held-out data.
