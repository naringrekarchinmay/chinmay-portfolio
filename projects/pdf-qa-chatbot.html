PDF Q&A Chatbot with RAG

Upload a PDF, ask questions in plain English, get answers grounded strictly in the document. A complete end-to-end RAG pipeline built from first principles.

GitHub Repo

Large language models don't inherently know what's inside your private documents. Retrieval-Augmented Generation fixes that and this project was built to understand exactly how, by implementing every stage of the pipeline by hand.

A user uploads a PDF and asks natural-language questions. Behind the scenes, the document is extracted and split into overlapping chunks, each chunk is embedded into a vector, FAISS finds the most relevant chunks for the question, and those chunks are injected into the LLM prompt so the answer is grounded in the actual document content rather than hallucinated.

Built as part of a generative AI learning journey, it's a clear, minimal reference implementation of how modern document-QA systems work under the hood — the same architecture that powers enterprise knowledge assistants.

Highlights

What it does.

📄

PDF ingestion

Text extraction from uploaded PDFs prepares raw document content for processing.

✂️

Chunking with overlap

Documents are split into overlapping chunks so context isn't lost at chunk boundaries.

🔢

Embeddings + FAISS

Each chunk becomes a vector; FAISS performs fast similarity search to retrieve the most relevant passages.

💬

Grounded answers

Retrieved context is injected into the prompt, so the LLM answers from the document — not from imagination.

Approach

How it was built.

01

Extract

Pull text from the uploaded PDF.

02

Chunk

Split the text into overlapping segments sized for retrieval.

03

Embed & index

Generate embeddings for every chunk and store them in a FAISS vector index.

04

Retrieve

Embed the user's question and find the most similar document chunks.

05

Generate

Compose a context-injected prompt and let the LLM produce an answer grounded in the retrieved passages.
