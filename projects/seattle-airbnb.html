Seattle Airbnb Dashboard

An interactive Tableau analysis of Seattle's short-term rental market. What drives price, where demand concentrates, and how a host should think about strategy.

Open in Tableau Public

Short-term rental hosts face the same questions as any business: what should I charge, when is demand highest, and which property attributes actually move revenue? This dashboard answers those questions for the Seattle Airbnb market.

Built in Tableau on Seattle listings data, it explores rental patterns across neighborhoods and seasons, isolates the factors most associated with price, and frames the findings as practical strategy for optimizing a short-term rental.
